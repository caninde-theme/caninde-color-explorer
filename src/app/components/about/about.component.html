ABOUT THE PROJECT

More than a color palette. Inspired by nature. Built for developers.

Canindé is an open-source color theme inspired by the vibrant colors of the Arara-Canindé — Brazil's iconic blue-and-yellow macaw.

We transform this natural palette into a consistent color system for code editors, terminals, and creative environments.

01

One identity. Multiple platforms.

Our goal is to bring the same visual language to the tools developers use every day, without losing consistency, accessibility, or character.

02

A system, not just a collection of colors.

Canindé uses a centralized token architecture. Core colors generate the palette, semantic roles define their purpose, and platform-specific packages map those roles to each application.

03

Designed to grow with the community.

The project is open source. Its future depends on people who want to bring Canindé to new platforms, improve its colors, and help shape its evolution.
